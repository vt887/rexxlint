# R009 — Line Too Long

## Description

Lines that exceed the profile's configured limits reduce readability and can cause problems on
older mainframe editors and terminals. R009 issues a **warning** at the soft limit and an
**error** at the hard limit.

| Profile              | Soft limit | Hard limit |
|----------------------|-----------|------------|
| `mainframe-compatible` | 72 chars  | 80 chars   |
| `standard`           | 100 chars | 200 chars  |
| `minimal`            | 200 chars | 200 chars  |

## Examples

**Bad** (mainframe-compatible, line > 80 chars):
```rexx
/* very long */
longVariableName = 'This is a very long string that exceeds eighty characters in total length here'
```

## Formatter Interaction

`--format` can wrap continuation lines; the specific wrapping strategy depends on statement type.
