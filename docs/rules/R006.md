# R006 — Unreachable Code After `EXIT`/`RETURN`

## Description

Any executable statement that follows an `EXIT` or `RETURN` at the same nesting level is dead
code and will never run. R006 highlights these statements to encourage cleanup.

## Examples

**Bad**:
```rexx
/* main */
DO
  EXIT 0
  say 'never reached'
END
```

**Good**:
```rexx
/* main */
EXIT 0
```

## False-Positive Considerations

- Rexx labels after `EXIT` are valid targets for `SIGNAL`; only executable statements (not label
  lines) are flagged.
- The check is limited to the immediately following statement — deeper unreachability analysis is
  deferred to a future AST-based pass.
