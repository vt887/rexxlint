# R007 — Unsafe `INTERPRET`

## Description

`INTERPRET expr` evaluates a dynamically constructed string as Rexx code at runtime. This is a
common source of injection vulnerabilities, unintended side-effects, and maintenance hazards.
R007 flags every use of `INTERPRET` as a warning.

## Examples

**Bad**:
```rexx
/* dynamic */
cmd = 'say "hello"'
INTERPRET cmd
```

**Recommendation**: replace with explicit branching or a `CALL` to a named procedure.

## False-Positive Considerations

- Some legacy programs rely heavily on `INTERPRET` for dynamic dispatch; disable with
  `/* rexxlint-disable R007 */` after deliberate review.
