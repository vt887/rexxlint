# R010 — Tabs Forbidden (mainframe-compatible profile)

## Description

The **mainframe-compatible** profile disallows tab characters in source files because many
mainframe editors and JCL submission utilities do not interpret `\t` as whitespace expansion.
R010 fires on any line containing a tab character when this profile is active.

## Examples

**Bad** (mainframe-compatible profile):
```rexx
/* tabbed */
	SAY 'indented with tab'
```

**Good**:
```rexx
/* spaced */
  SAY 'indented with spaces'
```

## Formatter Interaction

`--format` replaces leading tabs with spaces (4 spaces per tab by default) when this rule is
active.

## Test Coverage

Covered by `r010_*` tests in `crates/rexx-rules/src/lib.rs`.
