# R008 — Inconsistent Keyword Casing

## Description

Rexx keywords (`DO`, `END`, `IF`, `THEN`, `ELSE`, `SAY`, `EXIT`, `RETURN`, `SIGNAL`, `CALL`,
`PARSE`, `PULL`, `DROP`, `INTERPRET`, …) should be consistently cased throughout a file.
R008 fires when a keyword is found in mixed or lower case while the rest of the file uses upper
case (or vice-versa, depending on the active profile).

Active under the **mainframe-compatible** profile where all keywords must be upper-case.

## Examples

**Bad** (mainframe-compatible profile):
```rexx
/* example */
do i = 1 to 10
  say i
end
```

**Good**:
```rexx
/* example */
DO i = 1 TO 10
  SAY i
END
```

## Formatter Interaction

`--format` normalises keyword casing when the active profile requires it.

## Test Coverage

Covered by `r008_*` tests in `crates/rexx-rules/src/lib.rs`.
