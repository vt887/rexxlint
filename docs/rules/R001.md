# R001 — Missing First-Line Comment

## Description

Every Rexx program must begin with a block comment (`/* ... */`) on the very first non-empty line.
This is a language requirement: without it many Rexx interpreters will not recognise the file as a
Rexx program.

R001 fires when the first non-empty line is not a complete block comment.

## Examples

**Bad** (triggers R001):
```rexx
say 'Hello, World!'
```

**Good**:
```rexx
/* Main entry point */
say 'Hello, World!'
```

## False-Positive Considerations

- Leading blank lines before the comment are allowed; R001 reports the line of the first non-empty
  content.
- Inline comment placement (`say 'x' /* ok */`) does not satisfy the requirement.

## Formatter Interaction

`--fix` / `--format` automatically inserts the mandatory comment when R001 would fire.
