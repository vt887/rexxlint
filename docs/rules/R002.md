# R002 — Bare `EXIT` Without Return Code

## Description

In most Rexx programs an `EXIT` statement should supply an explicit numeric return code so that the
caller can distinguish success from failure. R002 fires when `EXIT` appears without an argument.

## Examples

**Bad**:
```rexx
/* calculate result */
EXIT
```

**Good**:
```rexx
/* calculate result */
EXIT 0
```

## False-Positive Considerations

- `EXIT` at the top-level of a script whose only purpose is interactive output may be intentional.
  Use a `/* rexxlint-disable R002 */` comment to suppress for that block.

## Formatter Interaction

No auto-fix; a return code must be chosen by the developer.

## Test Coverage

Covered by `r002_*` tests in `crates/rexx-rules/src/lib.rs`.
