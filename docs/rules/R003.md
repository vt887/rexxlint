# R003 — `SIGNAL` to Undefined Label

## Description

`SIGNAL <label>` transfers control to `<label>:`. If the label does not exist anywhere in the
program R003 fires, preventing a runtime `NOVALUE` or `SYNTAX` condition.

## Examples

**Bad**:
```rexx
/* handler */
SIGNAL cleanup
```

**Good**:
```rexx
/* handler */
SIGNAL cleanup
cleanup:
  say 'Cleaning up'
  EXIT 0
```

## False-Positive Considerations

- Externally defined includes are not resolved; disable R003 for multi-file programs with
  `/* rexxlint-disable R003 */`.
- `SIGNAL ON/OFF SYNTAX|ERROR|HALT|NOVALUE|NOTREADY` (condition handlers) are not flagged.
