# R005 — Duplicate Label

## Description

Two or more labels with the same name in one program cause ambiguous `SIGNAL`/`CALL` targets and
are a runtime error on strict interpreters. R005 fires on the second (and any further) occurrence
of a duplicate label.

## Examples

**Bad**:
```rexx
/* router */
start:
  say 'a'
start:
  say 'b'
```

**Good**:
```rexx
/* router */
start:
  say 'a'
continue:
  say 'b'
```

## False-Positive Considerations

- Label detection is case-insensitive; `Start:` and `START:` are treated as duplicates.

## Formatter Interaction

No auto-fix; the developer must rename labels manually.

## Test Coverage

Covered by `r005_*` tests in `crates/rexx-rules/src/lib.rs`.
