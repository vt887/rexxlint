# R004 — `DROP` of Undeclared Variable

## Description

`DROP var` removes a variable from the current environment. Using `DROP` on a name that was never
assigned is likely a typo or leftover dead code. R004 flags this pattern.

## Examples

**Bad** (x was never assigned):
```rexx
/* example */
DROP x
```

**Good**:
```rexx
/* example */
x = 42
DROP x
```

## False-Positive Considerations

- Rexx variables can be implicitly initialised to their own name (`x` → `"X"`), so many programs
  legitimately `DROP` variables that were only used through symbolic references. Tune with
  `/* rexxlint-disable R004 */` where needed.
